# Job Hunt Tracker

A simple Streamlit-based job application tracker built to manage and organize internship and job applications across multiple platforms in one place.

## Features

- Add and track job applications
- Store company name, role, portal, and application status
- Filter applications based on status
- Simple and clean UI using Streamlit
- Lightweight and easy to use

## Tech Stack

- Python
- Streamlit
- Pandas

## Purpose

Managing applications across different job portals becomes messy very quickly. This project was built as a personal tool to keep track of applications, follow-ups, and progress during internship and job hunting.

## Future Improvements
